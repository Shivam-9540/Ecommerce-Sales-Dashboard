# E-Commerce Sales Analysis Dashboard 📊

## Overview

This project analyzes e-commerce sales data to understand sales performance, profitability, market share, and customer acquisition trends.

An interactive Tableau dashboard was developed to visualize key business metrics and support data-driven decision-making.

## Dataset

- **Dataset Name:** `Ecommerce Sales.csv`
- **Records:** 115,746
- **Columns:** 20
- **Data Type:** E-commerce sales and order data

### Key Features

- Sales and profit
- Product categories
- Order quantity and order dates
- Customer segments and locations
- Markets and order regions
- Product prices and profit margins

## Tableau Dashboard

The Tableau workbook includes the following visualizations:

- **Sales KPI:** Overview of sales performance.
- **Profit KPI:** Overview of profitability.
- **Order Quantity KPI:** Summary of order quantities.
- **Category-Wise YTD vs PYTD Sales:** Comparison of current and previous-year sales.
- **Market Share by Sales:** Analysis of sales contribution across markets.
- **Market-Wise Customer Acquisition per Month:** Monthly customer acquisition trends across markets.

## How to Run

1. Download or clone the project repository.
2. Install and open **Tableau Desktop**.
3. Open `Ecommerce Sales Dashboard.twb`.
4. If prompted, reconnect the data source to `Ecommerce Sales.csv`.
5. Refresh the data if required.
6. Explore the dashboard and its visualizations.

### Prerequisites
- Tableau Desktop
- `Ecommerce Sales.csv`
- `Ecommerce Sales Dashboard.twb`
